# Synthetic provider evaluation v1

Run only against an isolated assistant database containing the approved demonstration corpus. No live bank facts, identities, credentials or personal questions belong in fixtures or reports. This executable uses real OpenAI Responses and embeddings requests. It is distinct from the deterministic test executable.

`dotnet run --project evaluations/Assistant.Evaluation.csproj -c Release` requires runtime DB connection, API key, pinned model/prices, embedding price and `ASSISTANT_EVAL_MAX_USD`. Before any call it reserves a conservative total ceiling of sample count times `ASSISTANT_MAX_REQUEST_USD`; each sample enforces the same cumulative cost and output limits as runtime. All original twenty fixtures remain; two relevance fixtures add unsupported USD versus supported AED and payment-completion-before-ledger questions. Twenty-two samples at USD0.02 require a ceiling of at least USD0.44. No retries.

The report records the actual active-index pointer read from PostgreSQL before provider calls. Do not activate or roll back policy indexes during an evaluation run; use the isolated immutable validation fixture. Cost is explicitly a conservative upper bound, not measured provider billing. The report measures specialist choice, typed policy intent and lexical versus hybrid Recall@5. It records the exact configured intent-specific question used by the evidence selector. Policy output is exact source excerpts with fixed framing, never free generated factual prose. Citation identifiers/approved sections are checked against retrieved chunks; identity alone does not establish relevance to the original question. Independent QA must grade intent fidelity, each quoted excerpt's relevance and supported claims against cited source, marking supported/unsupported/conflicting, and compute supported claims / all claims. Grade refusal and unanswerable cases explicitly. Original release thresholds remain: Recall@5 >=0.90; correct tool choice >=0.95; citation validity1.00; supported policy claims >=0.95. Typed intent accuracy additionally must reach0.95; numerical gate failures exit nonzero while independent semantic grading remains separately pending. Small synthetic samples do not establish production safety. Failures remain failed samples, never excluded from tool-choice or answerable retrieval denominators. Bank facts, ownership, empty history and outages require separate acceptance tests.
