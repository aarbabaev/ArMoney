# Service decisions

This service is the implemented C# exception proposed in repository ADR0020. Domain types reference the .NET base library only. Application ports keep provider, local retrieval and delegated bank reads separate; no business classes or database of another service are shared.

Policy source/chunks stage in a separate PostgreSQL transaction. Digest and immutable document/version identity prevent in-place replacement. A singleton active index pointer atomically activates/rolls back a complete staged index. V003 seals every published index permanently, including after rollback; new documents/versions and embedding mutation are forbidden once sealed, while identical reingestion changes nothing. Stage, embedding writes and activation share a per-index PostgreSQL advisory transaction lock, and embedding writes recheck publication after external calls finish. Operator activation/rollback require explicit lexical/hybrid mode; hybrid activation rejects any missing pinned embedding before changing the active pointer. Lexical mode intentionally allows lexical-only indexes. Operator credentials migrate/ingest; runtime has SELECT grants only. Exact vector1536 cosine ranking plus lexical reciprocal-rank fusion is optional and measured against lexical baseline; no approximate vector index is justified by the bounded initial corpus. Documents, effective dates, source revision/provenance and index/chunker versions remain available for traceable evidence.

Delegation handle stays request-local and is never persisted or sent to a provider. Direction-specific keys authenticate fixed gateway callbacks; authoritative sessions remain in gateway. Typed financial facts are rendered by the service, while provider output can choose only validated read specialists and cite local policy evidence. Request budgets/cancellation and final authorization checks live outside prompts. Conversations are not stored; external retention remains governed by provider/account controls despite store=false.

Policy prose is extractive: the structured planner selects a finite approved policy intent; the server derives a specific generic question and retrieval phrase, filters approved demonstration sections, then quotes exact selected source excerpts. The model cannot introduce factual answer prose. Unsupported policy categories return fixed insufficient evidence. This trades open-ended answering for traceability and faithful question categories; new categories require explicit intent/section extension and evaluation. Independent model evaluation still checks relevance and intent selection.
