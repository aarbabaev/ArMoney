# M1 delivery plan

Implemented: bootstrap, auth registration/login/me/logout, current-user profile
upsert/read and wallet metadata creation/listing through gateway. Wallet retries
converge on one wallet per identity/currency; balances and payments remain absent.

Next:
1. Ledger account provisioning and atomic P2P posting: balanced immutable entries,
   deterministic locks, insufficient funds, payload-matched idempotency and concurrency.
2. Payment orchestration: requester-scoped idempotency, durable PENDING recovery,
   reconciliation after uncertain outcomes, bounded retries and timeouts.
3. Gateway P2P endpoints and complete acceptance scenarios.
4. Production identity controls, observability and operational hardening.

M1 is complete only when authorized same-currency P2P changes balances exactly once,
concurrent/retried requests cannot overspend, entries balance, crash recovery
converges and real PostgreSQL tests prove these properties. This slice is not M1 completion.
